# Separation Heist — מבצע הפרדה

Plan a clever equipment route through a tiny 3D museum vault, then execute a timed nonviolent heist that recovers the components of a stolen mixed-material sample.

Status: design handoff; builder implementation is starting. Proposed screenshot images are visual targets, not proof of implemented gameplay.

See [BUILD_HANDOFF.md](BUILD_HANDOFF.md) and [COMMON.md](COMMON.md) for curriculum, asset workflow and acceptance criteria.

The intended stack is TypeScript with a real 3D engine, Hebrew RTL interface and a browser-playable single-player slice. Local development port: 5192.
